# Flight Price Prediction

A regression notebook for exploring and predicting flight ticket prices.

## Workflow
- Load and explore the flight dataset.
- Prepare features for modelling.
- Train and compare eight regression models.
- Evaluate models using R-squared (R²), mean absolute error (MAE), and root mean squared error (RMSE), including cross-validation.

## Tools
Python, Jupyter Notebook, pandas, NumPy, Matplotlib, and scikit-learn.
