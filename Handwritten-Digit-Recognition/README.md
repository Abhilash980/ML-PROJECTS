# Handwritten Digit Recognition

A machine learning notebook focused on recognizing handwritten digits from image data.

## Workflow
- Prepare the digit image data.
- Split the data into training, validation, and test sets.
- Train and compare seven classification approaches.
- Evaluate models using validation accuracy and macro-F1.

## Tools
Python, Jupyter Notebook, NumPy, pandas, Matplotlib, and scikit-learn.
