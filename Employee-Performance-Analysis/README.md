# Employee Performance Analysis

**Project:** INX Future Inc – Employee Performance Analysis (IABAC Project 10281)

## Objectives
1. Analyze employee performance by department.
2. Identify the top three factors affecting performance ratings.
3. Train and evaluate a machine-learning model to predict `PerformanceRating`.
4. Generate supporting analysis and plots for recommendations.

## Notebook
The project notebook is intended to be run in Google Colab. Upload the source Excel dataset when prompted.

## Dependencies
```bash
pip install pandas numpy matplotlib seaborn scikit-learn openpyxl xlrd joblib
```

## Outputs
The notebook is designed to generate department performance, correlation heatmap, confusion matrix, feature-importance plots, and a saved model file.

**Dataset:** The original Excel dataset is not included in this repository.
